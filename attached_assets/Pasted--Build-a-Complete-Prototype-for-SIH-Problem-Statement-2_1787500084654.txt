# Build a Complete Prototype for SIH Problem Statement 26092

## Project Name

**SchemeSathi**

### Tagline

**"Find the right scheme. Choose the right partner. Move forward with confidence."**

---

# 1. PROJECT OBJECTIVE

Build a polished, production-style full-stack web application prototype for **Smart Scheme Matching for Marginalized Entrepreneurs**, based on SIH Problem Statement **26092** from the **Ministry of Social Justice and Empowerment, Department of Social Justice and Empowerment**.

The platform should help eligible citizens/entrepreneurs:

1. Understand which government financial scheme is suitable for them.
2. Check basic eligibility.
3. Get ranked scheme recommendations.
4. Understand why a scheme was recommended.
5. Calculate estimated EMI.
6. Find the most suitable nearby authorized channel partner.
7. Start a guided application.
8. Track application progress.
9. Use the platform in multiple languages.

This is a **hackathon prototype**, not a real government loan processing system.

Use clearly marked **prototype/demo data** wherever real government APIs, live partner data, NPA data, or official integrations are unavailable.

---

# 2. IMPORTANT PRODUCT PRINCIPLE

Do NOT build this as a simple "loan calculator."

The core product is:

**Citizen Need → Eligibility → Intelligent Scheme Matching → Explainable Recommendation → Financial Planning → Partner Routing → Application Tracking**

The main differentiator is that the system should recommend the **right scheme AND the right channel partner**.

# 17. SCHEME MATCHING ENGINE

Implement a real rule-based scoring engine.

Do NOT hardcode only one result.

The engine should:

1. Filter clearly incompatible schemes.
2. Calculate a compatibility score.
3. Rank eligible schemes.
4. Generate explanation reasons.

Use a transparent weighted score.

Example:

```text
Income compatibility: 25%
Project type compatibility: 25%
Loan amount compatibility: 20%
Applicant type compatibility: 15%
Purpose compatibility: 10%
Other eligibility: 5%
```

Normalize score to 0–100.

Example output:

```text
Micro Finance Scheme
94% Match

Term Loan Scheme
78% Match

Educational Loan Scheme
12% Match
```

These numbers should be dynamically generated based on user inputs.

# 23. FINANCIAL CALCULATOR

Build a fully interactive EMI calculator.

Inputs:

Loan Amount

Interest Rate

Tenure

Moratorium

Use formula:

EMI = P × r × (1+r)^n / ((1+r)^n − 1)

Where:

P = principal

r = monthly interest rate

n = number of monthly installments

Update EMI instantly.

Display:

### Estimated EMI

₹X,XXX/month

Also show:

* Principal
* Total interest
* Total repayment

Create a Recharts donut/bar visualization.
